# BrandMyCup — Custom Branded Paper Cups Studio

## How to Upload to GitHub & Deploy Free on Vercel

1. Extract `brandmycup-github-ready.zip` on your computer.
2. Open **GitHub** (`github.com`), create a new repository (e.g., `brandmycup`), and upload the contents (`index.html`, `package.json`, `src/`).
3. Open **Vercel** (`vercel.com`), click **Add New... -> Project**, import your `brandmycup` repository, and click **Deploy**.
